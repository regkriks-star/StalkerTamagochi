# ЗОНА / КПК

Согласовано: забота через короткие вылазки, реалистичный КПК, накапливающиеся ошибки ухода, самостоятельный выбор фракции либо решение героя по его поступкам. После смерти весь хабар остаётся в рюкзаке на месте гибели. Новый герой может забрать его; прежний остаётся в журнале.

## Визуальное решение

Корпус #252b26; стекло #151b17; текст #dedfd0; оливковый фосфор #abb593; янтарь #c8aa70; опасность #cc8070. Oswald для названия и рангов, IBM Plex Sans для читаемого русского интерфейса, системный monospace только для показаний приборов.

Большая фотографичная сцена с героем — главный визуальный элемент. Физический корпус со скруглёнными углами и крепежом; внутри спокойные плоские приборные панели. Янтарный цвет означает действие/внимание, зелёный — состояние, красный — опасность. Текст выровнен влево.

Создание персонажа: обязательное окно перед первой жизнью и после выбора нового сталкера. Слева предпросмотр в обычной одежде, справа семь лиц и одно действие «Войти в Зону». На телефоне предпросмотр над выбором. Палитра и шрифты КПК сохранены. Выбранное лицо отмечается янтарной рамкой и галочкой; переключение — стандартная радиогруппа с управлением клавиатурой. Независимые слои тела, лица, противогаза и костюма совмещаются в одной системе координат. Фон локации расположен отдельно под ними; новые пейзажи будут добавлены позднее.

```text
┌ корпус / название прибора / время / установка ─────────┐
│ вкладки: Сталкер · Карта · Рюкзак · Журнал             │
│ позывной / текущая задача                              │
│ ┌ сцена + герой ──────────┐ ┌ состояние и уход ───────┐ │
│ │ место / экипировка     │ │ здоровье / еда / отдых │ │
│ └────────────────────────┘ └────────────────────────┘ │
│ ближайшая вылазка             входящие сообщения      │
└ серийный номер / статус сохранения ───────────────────┘
```

Проверка замысла: в центре живой герой, а не сетка одинаковых карточек аналитики. Приборная эстетика оправдана темой и явным выбором пользователя. На телефоне одна колонка; вкладки сохраняются, основные действия доступны без модальных цепочек. Уважать reduced-motion, обеспечить управление клавиатурой и видимый фокус.

## Уточнения по референсам и игровому циклу

Опора — третий референс пользователя: потёртый корпус КПК, янтарные действия, реалистичная карта и фронтальный портрет со слотами. Палитра дополнена янтарём #e6b65d, стеклом #141713 и линиями #a2957038. Шрифты сохранены: Oswald для заголовков, IBM Plex Sans для интерфейса. На телефоне навигация закреплена снизу. Иллюстрации — отдельные WebP-ассеты; все кнопки, слоты и маршруты интерактивные.

Карта: текущая позиция → маршрут → событие → продолжение → точка назначения. Безопасные поселения открывают торговлю и отдых, точки интереса — поиск тайников. Сталкер: портрет со слотами костюма, противогаза и двух оружий, состояние, ручное использование припасов. Рюкзак: категории, вес 50 кг, экипировка, использование, продажа и оставление предметов.

Уведомление нужно открыть за 15 минут; после открытия штрафной таймер остановлен, выбор сохраняется при перезагрузке. Неоткрытое событие приводит к ранению или ограблению. Пользователь выбрал статический сайт: системные уведомления только при работающей открытой игре, без сервера.

## Границы первого прототипа

Три опасные точки, два безопасных поселения, пять типов событий, четыре фракции и одиночки, три артефакта с побочными эффектами, торговля, негативные последствия пропущенных событий, смерть и возврат к рюкзакам. Локальное сохранение, установка и офлайн после первого открытия. Без сервера и фоновой push-доставки; системные уведомления открытой игры через service worker. Закрытый браузер не исполняет игру: прошедшее время рассчитывается при возвращении.

Первый штраф ухода через 24 часа без еды, воды или отдыха; второй через 48 часов; смерть через 72. Одновременное отсутствие нескольких видов ухода считается одной ступенью, а не мгновенной смертью. Выполнение нужного ухода снимает ступени, но здоровье нужно восстановить. Реальные часы не ускоряются автоматически; отдельные кнопки в настройках позволяют проверить течение времени.

Деплой — GitHub Actions при пуше в `main` (`regkriks-star/StalkerTamagochi`); сборка выполняется в CI, локально — для проверки.
