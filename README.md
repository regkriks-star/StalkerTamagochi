# ЗОНА — персональный КПК

Игровой прототип «Сталкер × Тамагочи» на React, TypeScript и Vite. Устанавливается как PWA и работает офлайн после первой полной загрузки. Язык интерфейса — русский.

**Репозиторий:** <https://github.com/regkriks-star/StalkerTamagochi>. Сайт собирается и публикуется через GitHub Actions: <https://regkriks-star.github.io/StalkerTamagochi/>.

## Запуск

Нужен Node.js 22.18+ либо 24/26. Тесты компилируются локальным TypeScript и не требуют встроенной поддержки TS в Node.

```sh
npm ci
npm run dev
```

Открыть <http://localhost:5173/StalkerTamagochi/>.

```sh
npm run build
npm run preview
```

Готовый статический сайт находится в `dist/`. Просмотр сборки: <http://localhost:4173/StalkerTamagochi/>. Не открывайте `index.html` через `file://`: для модулей и service worker нужен HTTP на localhost или HTTPS.

## Что можно делать

- При первом запуске и после смерти создать сталкера: выбрать одно из семи лиц с предпросмотром, включая лицо по фотографиям. До нажатия «Войти в Зону» время ухода не идёт. Начальная одежда — обычный свитер и брюки; куртка лежит в рюкзаке.
- Кнопка «Самоубийство» под персонажем завершает его жизнь после подтверждения, в том числе в пути и во время события. При любой смерти на карте остаётся тело со всеми припасами, надетыми вещами, артефактами и деньгами. Следующий сталкер может забрать их по вместимости; остаток не пропадает.
- Видеть надетую куртку, комбинезон и противогаз на персонаже. Изображение собирается из прозрачных слоёв; снятый противогаз возвращает выбранное лицо. Фон локации выделен отдельно, иллюстрации локаций можно добавить позже.
- Следить за здоровьем, сытостью, водой, силами и радиацией. Еду, воду, аптечки и антирад нужно применять вручную из рюкзака или быстрого меню, в том числе в пути.
- Выбрать точку на карте и идти туда в реальном времени. Длительность зависит от расстояния: например, из деревни на Кордон — 8 минут. Сталкер остаётся в точке назначения. Возвращение в поселение — отдельный маршрут.
- В пути с вероятностью 80% появляется одно случайное событие в случайный момент между 25% и 75% маршрута. События включают бандитов, аномалию, сигнал SOS, патруль и выброс. Уведомление видно из любого раздела КПК.
- **Открыть событие за 15 минут.** Открытие останавливает штрафной таймер, а дорога ждёт выбора действия. Бандитов можно обойти (+6 минут), атаковать ради трофеев или заплатить 150 ₽. Открытие на самой границе срока считается опозданием.
- Без открытия сообщения бандиты забирают 30% денег и четверть каждого ненадетого предмета с округлением вверх. В остальных событиях сталкер получает 25 урона и облучение. Награды за пропуск нет; дорога продолжается. Последствия применяются однократно, в том числе после перезагрузки.
- Носить **до 50 кг**, включая экипированные вещи. В «кукле» есть костюм, противогаз, основное и дополнительное оружие. Купленные вещи нужно надеть: броня в рюкзаке не защищает. Противогаз уменьшает облучение; автомат снижает урон боя с бандитами.
- Покупать и продавать предметы у Сидоровича в Деревне новичков или у Бармена в «100 рентген». Отдых доступен в безопасных поселениях. Торговать в дороге и на опасной точке нельзя.
- Осматривать точки интереса, находить тайники с припасами, деталями и артефактами. Поиск стоит 10 сил, повторный поиск на той же точке доступен через 30 минут. В бою с бандитами можно получить расходники и деньги.
- Оставлять вещи на карте и забирать позже. Излишки найденной добычи сохраняются на точке, покупки при переполнении не проходят. Рюкзаки погибших забираются частями по вместимости; вещи и деньги не дублируются.
- Использовать три артефакта с преимуществами и побочными эффектами. Получать опыт за завершённые переходы, выбирать фракцию после трёх переходов. После смерти новый герой может вернуть вещи предшественника.

### Уведомления

В настройках КПК нажмите **«Включить уведомления»**. Системный запрос разрешения появляется только после этого действия. В поддерживаемом браузере событие создаёт уведомление через service worker; нажатие открывает соответствующее событие. Если разрешение отклонено или API недоступен, сообщение остаётся внутри КПК. Звук рации включается отдельно.

По выбранному режиму это **статический сайт без push-сервера**. Уведомления создаются, пока браузер выполняет открытую игру. При закрытом или приостановленном браузере доставка не гарантируется: при следующем открытии игра рассчитывает прошедшее время и последствия. PWA сама по себе не обеспечивает фоновую доставку.

### Уход и реальное время

Последний приём еды, воды и отдых учитываются отдельно. 24 часа без одного из необходимых видов ухода дают первую ошибку: снижение здоровья и его максимума. 48 часов — вторую. 72 часа — смерть. Одновременный пропуск еды и воды не вызывает две ошибки сразу.

Чтобы снять ошибку, нужно восполнить все просроченные потребности. Здоровье затем восстанавливается отдельно. Высокая радиация и артефакты меняют состояние, но один пропуск ухода сам по себе не убивает. В опасной вылазке можно погибнуть от урона.

В настройках есть **«+1 минута»**, **«+15 минут»** и **«+24 часа без ухода»** для быстрой проверки. Они изменяют текущее сохранение. Через три суточных перемотки без ухода можно проверить смерть, нового сталкера и возврат вещей.

### Сохранение и PWA

Прогресс автоматически сохраняется в localStorage этого браузера (`zone-pda.save.v1`), включая лицо, этап создания персонажа, экипировку, местоположение, случайные события, открытие сообщений, добычу на земле, рюкзаки погибших, журнал и сдвиг времени. Формат сохранения — версия 3; сохранения версий 1 и 2 автоматически мигрируют без удаления вещей и получают первое лицо. В настройках можно выгрузить JSON для архивной копии; загрузка такой копии через интерфейс пока не реализована. Повреждённый JSON сохраняется отдельно под ключом `zone-pda.save.v1.corrupt`, а приложение сообщает о новой истории.

Закрытый браузер не выполняет таймеры игры: при возвращении модель рассчитывает прошедшее время и все положенные последствия по порядку. Фонового push-сервиса, облачной синхронизации и аккаунтов в прототипе нет. Удаление данных сайта удалит прогресс. Несколько вкладок синхронизируются через браузерное событие storage; серверной синхронизации нет.

На Android/компьютере используйте «Установить КПК» либо меню браузера. На iPhone: Safari → Поделиться → На экран Домой. Установка не требуется для игры в браузере. Разработка через `npm run dev` идёт без service worker; PWA проверяется на production-сборке.

## Проверка

```sh
npm test
npm run build
npm run test:e2e
```

Тесты логики проверяют границу 15 минут, открытые события, штрафы, вместимость, экипировку, торговлю, тайники, миграцию старых сохранений, уход, смерть и наследование. Браузерные проверки проходят маршруты, экипировку, торговлю, мобильные экраны, перезагрузку, уведомления service worker и офлайн PWA. Если Chrome не установлен, один раз выполните `npx playwright install chromium`.

## Деплой на GitHub Pages

Сайт: <https://regkriks-star.github.io/StalkerTamagochi/> (после первого успешного деплоя). `base` в `vite.config.ts`, manifest, scope и start_url — `/StalkerTamagochi/`, поэтому имя репозитория менять нельзя без правки конфига. Сборка отключает source maps; в `dist/` попадают только файлы сайта и лицензии зависимостей.

**`npm run build` ничего не публикует.** Деплой выполняет workflow [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml) при каждом пуше в `main`: ставит зависимости, собирает `npm run build` и отправляет `dist/` в GitHub Pages.

Разовая настройка на GitHub: workflow пытается включить Pages сам (`enablement: true`); если GitHub этого не разрешит — **Settings → Pages → Source: GitHub Actions** (ветку не выбирать). После этого каждый пуш в `main` обновляет сайт; ход деплоя виден на вкладке **Actions**.

SSH-доступ настраивается один раз: ключ `~/.ssh/id_ed25519`, публичная часть добавляется в **Settings → SSH and GPG keys**. Проверка: `ssh -T git@github.com` → `Hi regkriks-star!`.

```sh
git push -u origin main
```

## Устройство проекта

- `src/game.ts` — модель времени, вылазок, ухода, фракций и наследия.
- `src/useGame.ts` — сохранение и восстановление.
- `src/App.tsx`, `src/style.css` — интерфейс КПК и адаптивная вёрстка.
- `src/CharacterPortrait.tsx`, `public/character/` — независимые слои персонажа: атлас шести лиц и отдельное седьмое лицо. [Промпты и совмещение](docs/CHARACTER-ASSETS.md).
- `vite.config.ts` — статический билд и офлайн PWA.
- `.github/workflows/deploy.yml` — сборка и публикация сайта при пуше в `main`.
- `DESIGN.md` — согласованные правила и визуальное решение.
- [docs/ASSETS.md](docs/ASSETS.md) — происхождение и промпты прежнего цельного портрета, карты и атласа предметов. Новые слои персонажа описаны в [docs/CHARACTER-ASSETS.md](docs/CHARACTER-ASSETS.md). Все растровые игровые ассеты созданы встроенным image_gen.
