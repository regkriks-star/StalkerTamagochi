# Глоссарий

**Сверено с кодом:** 20.11.2026.

## Игровые термины

| Термин | Значение |
|---|---|
| **Зона** | Мир игры; 5 локаций, аномалии, артефакты, группировки |
| **КПК / ПДА** | Интерфейс игры; «персональный КПК» в названии |
| **Сталкер** | Управляемый персонаж; одна жизнь на поколение |
| **Поколение** | Номер жизни (`generation`), начинается с 1 |
| **Вылазка / рейд** | Переход между локациями, возможно с событием |
| **Переход** | Завершённый рейд; даёт +20 XP |
| **Событие** | Случайная встреча в пути; 5 типов + событие у могилы |
| **Хабар** | Добыча: детали, артефакты, припасы |
| **Тайник** | Результат «Осмотреть точку»; может остаться на земле |
| **Земля / `ground`** | Вещи, оставленные на карте, по локациям |
| **Могила / тело** | Вещи и деньги погибшего; забираются по вместимости |
| **Мемориал** | Запись о погибшем в «Памяти Зоны» |
| **Ошибка ухода** | Штраф за 24/48/72 часа без еды, воды или отдыха |
| **Дедлайн ухода** | Время следующей ошибки |
| **Сытость / вода / силы** | Основные потребности, 0–100 |
| **Радиация** | 0–100; выше 40 бьёт по здоровью |
| **Фракция / группировка** | Долг, Свобода, Учёные, Наёмники; плюс «одиночка» |
| **Репутация** | Очки близости к фракциям; +2 за выбор события |
| **Артефакт** | Пассивный бонус с побочным эффектом; один на поясе |
| **Детектор** | Предмет «Отклик»; сейчас без механики |
| **Противогаз** | Слот маски; радиация в событиях ×0,5 |
| **Комбинезон** | Слот костюма; урон в вылазках ×0,65 |
| **Слот** | Костюм, противогаз, основное оружие, вторичное оружие |
| **Рюкзак / инвентарь** | Все предметы; лимит 50 кг |
| **Вес** | Суммарный вес всех предметов, включая надетые |
| **Поселение** | Безопасная локация: торговля, отдых |
| **Точка интереса** | Опасная локация: поиск тайников, события |
| **Выброс** | Одно из событий; высокий урон/радиация |
| **Бандиты** | Событие 0; крадут деньги/вещи при пропуске |
| **SOS / патруль** | События 2/3; свои наборы вариантов |
| **ПМ** | Пистолет Макарова; стартовое вторичное оружие |
| **АК-74** | Винтовка; снижает урон боевых выборов |
| **«Заря»** | Комбинезон; снижает урон |
| **ГП-5** | Противогаз; снижает радиацию |
| **«Отклик»** | Детектор аномалий; флейвор |
| **Кровь камня** | Артефакт: лечит, усиливает голод |
| **Вспышка** | Артефакт: экономит силы, усиливает жажду |
| **Ночная звезда** | Артефакт: больше денег, больше радиации |

## Локации

| id | Название | Тип |
|---|---|---|
| `camp` | Деревня новичков | безопасная, Сидорович |
| `bar` | Бар «100 рентген» | безопасная, Бармен |
| `cordon` | Кордон | опасная, низкий риск |
| `dump` | Свалка | опасная, средний риск, нужен 40 XP |
| `agroprom` | Агропром | опасная, высокий риск, нужно 100 XP |

## Технические термины

| Термин | Значение |
|---|---|
| **Reducer** | `reduceGame(prev, action, realNow)` — чистая функция нового состояния |
| **Action** | Команда: `tick`, `raid`, `choice`, `buy`, `equip`, `skip` и т.д. |
| **Tick** | Ежесекундное обновление времени |
| **Catch-up** | Догон пропущенного времени в `applyTime` |
| **Save v3** | Текущий формат JSON в `localStorage` |
| **Migration** | Преобразование старого save в новый |
| **Seed / PRNG** | Детерминированный генератор; LCG в `random(game)` |
| **Structured clone** | Глубокое копирование состояния в reducer'е |
| **Ground** | Вещи на карте |
| **Grave** | Тело погибшего |
| **Memorial** | Запись о погибшем |
| **Phase** | `travel`, `choice`, `return` |
| **`packWeight`** | Функция веса рюкзака |
| **`maxHealth`** | Максимум здоровья с учётом ошибок |
| **`isSafe`** | «Не в рейде и локация безопасна» |
| **`isEquipped`** | Предмет надет/на поясе (по типу) |
| **PWA** | Progressive Web App; установка и офлайн |
| **SW / Service Worker** | Фоновый скрипт кэша и уведомлений |
| **Precache** | Список ассетов, скачиваемых заранее |
| **Workbox** | Библиотека для SW (генерируется `vite-plugin-pwa`) |
| **Manifest** | Метаданные установки PWA |
| **Scope / base** | `/StalkerTamagochi/` |
| **Top layer** | Слой нативных `<dialog>`/popover над `z-index` |
| **SPA** | Одностраничное приложение без роутера |
| **ADR** | Architecture Decision Record |
| **E2E** | End-to-end тест в браузере |
| **Smoke** | Быстрая проверка основного сценария |

## Соглашения об именах

- Идентификаторы в коде и сохранениях — английские (`camp`, `stone`,
  `food`), тексты UI — русские.
- Компоненты React — PascalCase (`CharacterScene`), функции — camelCase
  (`reduceGame`), константы — UPPER_SNAKE (`PACK_CAPACITY`).
- CSS-классы — kebab-case, BEM-подобные (`care-panel`, `map-point`,
  `item-card`).
- Файлы знаний — `UPPER-KEBAB.md` в `docs/knowledge/`, кроме этого глоссария
  (`GLOSSARY.md`).
- Не переименовывай id локаций/предметов/событий: они попадают в save.
