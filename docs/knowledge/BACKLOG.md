# Бэклог

**Основано на аудите 20.11.2026.**  
Статусы: `todo` — не начато, `doing` — в работе, `blocked` — нужен ответ,
`idea` — идея без решения, `done` — закрыто. При закрытии задачи добавь запись
в [`CHANGELOG.md`](CHANGELOG.md) и обнови профильный документ.

## Как пользоваться

- Не начинай с P2, пока P0 не закрыт: сейчас нет доверенного quality gate.
- Одна задача — один проверяемый результат. Не смешивай рефакторинг и фичу.
- Для каждой задачи есть «Готово, когда»; этого достаточно для приёмки.
- Если задача меняет сохранение — сначала прочитай
  [`SAVE-AND-TIME.md`](SAVE-AND-TIME.md).

### AUD-002. E2E-гонка при инъекции сохранения

**Статус:** `done` (20.11.2026)  
**Где:** `tests/prototype.spec.ts` (тест «opened event…»),
`src/useGame.ts`.

**Проблема:** тест пишет `localStorage`, затем сразу reload. Приложение
каждую секунду перезаписывает save, поэтому инъекция может быть потеряна.
В прогоне тест получил старую игру и не нашёл «15 минут без связи».

**Готово, когда:**

- [ ] save пишется через `page.addInitScript` до загрузки **или** таймер
  останавливается на время инъекции;
- [ ] тест стабильно проверяет именно догон штрафа;
- [ ] тест не зависит от скорости машины.

### AUD-011. Масштаб страницы и мелкий текст

**Статус:** `doing` — zoom разрешён, мелкий текст остался.  
**Где:** `index.html`, `src/main.tsx`, `src/style.css`.

**Проблема:** `maximum-scale=1, user-scalable=no` + глобальный
`preventDefault`; часть подписей 5–9px. Нарушение WCAG 1.4.4.

- [ ] pinch-zoom разрешён вне карты;
- [ ] `touch-action: none` только на `.zone-map`;
- [ ] смысловой текст ≥ 12px, служебный ≥ 10px;
- [ ] проверено при 200% zoom.

вкладке.
