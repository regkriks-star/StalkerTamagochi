**Тип:** инфраструктура, документация.

**Что изменено:**

## 2026-11-20 — исправлены P0/P1 аудита

**Тип:** код, тесты, PWA, инфраструктура.

**Что изменено:**

- E2E: синхронизирован текст кнопки могилы; инъекция сохранения переведена на
  `addInitScript` (больше нет гонки с автосейвом); конфиг собирает `dist` перед
  preview, timeout 90 с, retries в CI, `reuseExistingServer: false`; тест жестов
  обновлён под разрешённый zoom.
- Онбординг: «Случайное имя» получило класс `secondary-button`; длинное имя
  переносится, ранг не уезжает; `parseSave` ограничивает имя 24 символами;
  мобильный CTA «Войти в Зону» закреплён внизу.
- Доступность: разрешён pinch-zoom страницы (глобальные `preventDefault`
  удалены, `touch-action` оставлен только на карте); hover primary-кнопки стал
  контрастным; добавлен верхний/боковой safe-area; error boundary с выгрузкой
  сохранения.
- Тосты: рендерятся порталом в открытый `<dialog>` и больше не прячутся под top
  layer.
- Перемотка: «+24 часа без ухода» подтверждается; при смерти модальное окно
  закрывается и показывается экран нового сталкера.
- PWA: седьмое лицо переведено в WebP (190 КБ вместо 1,47 МБ PNG); precache
  очищен от дублей и неиспользуемых `scene.webp`/`stalker.webp` —
  32 записи, ~2,9 MiB вместо 42 и 4,61 MiB.
- Инфраструктура: `engines.node`, `.nvmrc`, GitHub Actions `verify.yml`;
  `scripts/test.mjs` + `tsconfig.test.json` компилируют тесты локальным
  TypeScript (встроенный TS в Node больше не нужен); `storage`-события с
  устаревшим `lastTick` игнорируются.
- Документация: обновлены `README.md`, `DESIGN.md`, `docs/ASSETS.md`,
  `docs/knowledge/*`; семь лиц вместо шести.

**Проверки:**

- `tsc --noEmit` — 0 ошибок.
- Юнит-тесты — 22/22.
- `npm run build` — успешно; JS ~321,0 кБ, CSS ~55,3 кБ.
- `npm run test:e2e` — **11/11**.
- `npm run test:publish` — успешно.
- Precache — 32 уникальные записи, ~2,9 MiB (отчёт Vite: 2 889,08 KiB + иконки манифеста).

**Влияние на сохранения:** схема не менялась; ужесточена валидация имени
(> 24 символов теперь отвергается). Миграция не требуется.

**Не сделано:** публикация на GitHub Pages (нужна явная команда), Git-репозиторий
исходников, LICENSE, throttling записи/рендера, полный аудит зависимостей.

## Правила

- Не переписывай старые записи задним числом; добавляй новую.
- Если дата неточная (нет Git), помечай «по артефактам/файлам».
- Указывай, какой билд опубликован (SHA), если он известен.
- Не вставляй сюда секреты и локальные абсолютные пути.
